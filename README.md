# CHECKMATE

**Understand the code. Master the craft.**

Eigenständige, lokale Desktop-Lernsoftware für Programmierung. Electron · React · TypeScript. Nur ChatGPT als KI-Anbieter; ohne API-Schlüssel-Zwang, sofern die offizielle Sign-in-with-ChatGPT-Freigabe erteilt wurde.

Die Umsetzung erfolgt über überprüfte Pull Requests; kein Push nach AutoDev Studio.
